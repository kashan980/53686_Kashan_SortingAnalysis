
Empirical Analysis of Sorting Algorithms in Worst-Case Scenarios

Project Description This project analyzes the performance of four sorting algorithms — Bubble Sort, Selection Sort, Insertion Sort, and Merge Sort — by measuring their execution time on different input sizes (5, 10, 50, 100 elements).
The algorithms are tested in worst-case scenarios, and the empirical results are compared to theoretical time complexities.

Technologies Used

Language: C++
Compiler: g++ (or any C++ compiler)
How to Compile and Run

Clone this repository.
Open the terminal/command prompt.

Compile the program using:

g++ main.cpp -o sorting_analysis
